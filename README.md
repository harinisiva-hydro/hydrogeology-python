\# Hydrogeology with Python



Notebooks and scripts for groundwater data analysis and modelling, built while learning Python for hydrogeology.



\## Contents

\- `01\_darcy\_basics.ipynb`: Darcy's Law and seepage velocity

\- `02\_numpy\_basics.ipynb`: arrays and model-style grids

\- `03\_pandas\_basics.ipynb`: cleaning and summarising water-level data

\- `04\_hydrograph.ipynb`: hydrograph with rainfall



All data in this repo is synthetic.
